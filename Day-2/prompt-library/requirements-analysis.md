# Requirements Analysis

## Prompt 1
```
Analyze this feature request as a senior product/technical analyst:

{{REQUEST_OR_PRD}}

Output: core goal (one sentence), functional requirements as testable statements, non-functional requirements, open questions, edge cases to handle, and any risks or conflicts. Flag ambiguity instead of guessing.
```

```

List discrete functional requirements, identify unstated assumptions and gaps, and call out edge cases (invalid input, permissions, scale, concurrency) not addressed in the original text.
```
