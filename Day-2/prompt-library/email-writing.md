# Email Writing

## Prompt 1
```
Write a professional email. Recipient/relationship: {{RECIPIENT}}. Goal: {{GOAL}}. Key facts: {{FACTS}}. Tone: {{TONE}}. Length: {{LENGTH}}. Lead with the point, include one clear call-to-action, no corporate filler. Output subject line + body only.
```

## Prompt 2
```
Draft an email to {{RECIPIENT}} about {{TOPIC}}. Context: {{CONTEXT}}. I need them to {{DESIRED_ACTION}} by {{DEADLINE}}. Keep it {{TONE}} and {{LENGTH}}. Provide two versions: one more direct, one more collaborative.
```
