# Week 2 – Day 2 Research

# 1. What is Gradio?

Gradio is an open-source Python library that helps developers create web applications for AI and machine learning models. It allows users to interact with models through a web browser without requiring HTML, CSS, or JavaScript. Gradio is widely used for building chatbots, image recognition systems, and other AI-powered applications.

---

# 2. Why is Gradio popular in AI development?

Gradio is popular because it is simple, fast, and designed specifically for AI projects. Developers can build an interactive interface in just a few lines of Python code. It supports popular AI models like Gemini, Ollama, OpenAI, and Hugging Face, making it an excellent choice for AI development and demonstrations.

---

# 3. Gradio vs Streamlit

| Gradio | Streamlit |
|---------|-----------|
| Mainly designed for AI and ML applications | Mainly designed for dashboards and data apps |
| Built-in chatbot and AI components | Strong data visualization support |
| Easy model deployment | Better for business analytics |
| Great for LLM applications | Great for reporting and dashboards |

**Conclusion:**  
Choose **Gradio** for AI applications and chatbots, while **Streamlit** is better for dashboards and data visualization.

---

# 4. What are Blocks in Gradio?

Blocks are Gradio's layout system used to build flexible and interactive applications. They allow developers to arrange components in rows, columns, tabs, and groups, making it easy to create professional-looking interfaces with multiple features.

---

# 5. What are Components?

Components are the building blocks of a Gradio application. They allow users to provide input and view output.

Common components include:
- Textbox
- Button
- Chatbot
- Image
- Audio
- Video
- Dropdown
- Slider
- Checkbox
- Markdown

Each component serves a specific purpose in the user interface.

---

# 6. What are Callbacks?

Callbacks are Python functions that execute when a user performs an action, such as clicking a button, submitting text, uploading a file, or changing a dropdown value. They connect the interface with the application's logic and make the app interactive.

---

# 7. What is Streaming?

Streaming is a technique where the AI response is displayed gradually as it is generated instead of waiting for the entire response. This provides a smoother and faster user experience, similar to ChatGPT, where users can start reading while the model is still generating text.

---

# 8. What is Markdown Rendering?

Markdown Rendering allows AI responses to be displayed with proper formatting. It converts Markdown syntax into a readable format, supporting headings, bullet lists, numbered lists, tables, hyperlinks, bold text, italics, and code blocks. This makes AI responses cleaner and easier to understand.

---

# 9. When should companies choose Gradio over React?

Companies should choose **Gradio** when they need to quickly develop AI prototypes, machine learning demos, internal tools, or chatbot applications using Python. It significantly reduces development time and requires little frontend knowledge.

For large-scale production websites that require complete control over design, animations, and complex user interactions, **React** is usually the better choice. Many organizations use Gradio for AI development and testing, then move to React when building a fully customized production application.
