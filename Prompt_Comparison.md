Prompt Comparison
1. Artificial Intelligence
- Bad Prompt

Tell me about AI.

- Improved Prompt

Explain Artificial Intelligence to a second-year Computer Science student in less than 300 words. Use simple language, include two real-world examples, and summarize the key points at the end.

- Why the original prompt was weak
Too broad and vague.
Doesn't specify the audience.
No word limit or desired format.
The AI may provide too much or too little information.

- Why the improved prompt is better
Clearly defines the audience.
Sets a word limit.
Requests simple language.
Asks for examples and a summary, making the response more useful and focused.

2. Python Programming
- Bad Prompt

Write Python code.

- Improved Prompt

Write a Python function that checks whether a number is prime. Include comments explaining each step and demonstrate the function with three example inputs and outputs.

- Why the original prompt was weak
Doesn't specify what the code should do.
No programming requirements.
No expected output.

- Why the improved prompt is better
Clearly defines the task.
Requests comments for better understanding.
Includes example usage and output.

3. Email Writing
- Bad Prompt

Write an email to principle.

- Improved Prompt

Write a professional email to my manager requesting one day of leave due to illness. Keep the tone polite, limit the email to 150 words, and include a clear subject line.

- Why the original prompt was weak
Doesn't specify the purpose.
No recipient or tone.
No formatting requirements.

- Why the improved prompt is better
Clearly identifies the purpose.
Specifies the recipient and tone.
Includes length and formatting requirements.

4. Translation
- Bad Prompt

Translate good into urdu.

- Improved Prompt

Translate the following English sentence into Urdu while preserving its original meaning and using natural, conversational language:

"Machine learning helps computers recognize patterns in data."

- Why the original prompt was weak
Doesn't mention translation style.

- Why the improved prompt is better
Specifies both source and target languages.
Provides the exact text.
Requests a natural and accurate translation.

5. Data Comparison
- Bad Prompt

Compare 2 programming languages.

- Improved Prompt

Compare Python, Java, and C++ in a Markdown table based on syntax, execution speed, learning difficulty, memory management, and common use cases. Conclude by recommending the best language for beginners and explain why.

- Why the original prompt was weak
Doesn't specify which languages.
No comparison criteria.
No desired output format.

- Why the improved prompt is better
Clearly identifies the languages to compare.
Specifies comparison criteria.
Requests a structured Markdown table.
Asks for a recommendation with justification.
